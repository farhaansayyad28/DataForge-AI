# DataForge AI

DataForge AI is a Python-based project that helps users work with raw datasets by automating common data engineering tasks such as data profiling, cleaning, transformation, and analysis. The aim of this project is to reduce the manual effort involved in preparing data and provide useful insights using AI.

## Features (Planned)

- Upload CSV, Excel and JSON files
- View dataset summary
- Detect missing values and duplicate records
- Generate a data quality score
- Clean and transform datasets
- Generate SQL table schema
- AI-based dataset analysis and recommendations
- Interactive charts and dashboards
- Export reports

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- SQLite
- SQLAlchemy
- Plotly
- Google Gemini API
- ReportLab

## Project Status

This project is currently under development. New features will be added gradually as different modules are completed.

## Why I Built This

The goal of this project is to learn practical data engineering concepts while building a tool that can automate data preparation tasks. It also serves as a portfolio project to demonstrate skills in Python, data processing, SQL, visualization, and AI integration.
